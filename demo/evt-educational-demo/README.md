# EVT Educational Demo

В этой директории хранится [оптимизированное техническое задание](PROMPT.md) на создание автономного учебного модуля GEV/GPD/AR. Оно отделено от существующих предметных конвейеров и предназначено для передачи coding agent или использования как план реализации.

## Как использовать сейчас

1. Откройте [`PROMPT.md`](PROMPT.md).
2. Передайте его coding agent из корня текущего репозитория.
3. После реализации агент должен создать структуру, описанную в промпте, внутри этой директории.
4. Проверка готовой реализации выполняется из `demo/evt-educational-demo/`:

```bash
python3 -m venv .venv
source .venv/bin/activate             # Windows PowerShell: .venv\Scripts\Activate.ps1
pip install -e .
python -m pytest -q
python scripts/run_demo.py --seed 42
```

Ожидаемые результаты реализации: `data/synthetic_data.csv`, таблица показателей в терминале и не менее четырёх PNG-файлов в `figures/`.

> Сейчас в директории находится спецификация, а не реализованный Python-пакет. Для уже работающего автономного smoke-test используйте синтетический пример мозга, команда которого приведена в основном [`README.md`](../../README.md#автономный-demo-пример-без-загрузки-исходной-ээг).
